# Changelog

## 0.48.0

- První instalace Lussi core přijme podepsaná vydání: doplněk zná veřejné klíče vydání stabilního i pilotního
  kanálu.

## 0.47.0

## 0.46.0

- Přechod mezi kanály Lussi agent a Lussi agent (pilot) bez nového párování: nainstaluj druhý doplněk, ve
  starém zapni volbu Předat data druhému kanálu a pak spusť nový.

## 0.45.0

- Lussi agent má dva kanály: Lussi agent (stabilní) a Lussi agent (pilot) pro zkušební domy.
- Stabilní kanál přijme jen stabilní vydání Lussi core, pilot jen pilotní.
